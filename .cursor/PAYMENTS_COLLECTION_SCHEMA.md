# HandyWorks Payments Collection Schema

**Date**: 2025-12-17  
**Collection**: `handyworks_payments`  
**Purpose**: Track individual payment records for invoices (supports partial payments)

## Overview

The `handyworks_payments` collection stores individual payment transactions. Each payment is an immutable record linked to an invoice. This design supports:
- Partial payments (multiple payments per invoice)
- Full audit trail (who recorded, when, how much)
- Multiple payment methods (Stripe, check, phone, fax, cash)
- Payment history per customer

## Collection Structure

### Collection Name
```
handyworks_payments
```

### Document ID
Auto-generated by Firestore (not using custom IDs)

### Document Schema

```javascript
{
  // Payment identification
  id: "auto-generated-firestore-id",
  invoice_id: "INV-2026-12345",  // Reference to handyworks_invoices document
  
  // Customer reference (denormalized for easy querying)
  acct_num: 12345,                // Account number
  customer_name: "John Smith",     // Customer name (denormalized)
  customer_email: "john@example.com", // Email (denormalized)
  
  // Payment details
  amount: 100.00,                  // Payment amount (dollars, not cents)
  payment_date: Timestamp,         // Date payment was received
  payment_method: "check",         // Payment method (see options below)
  
  // Payment reference/tracking
  payment_reference: "Check #1234", // Optional: check number, transaction ID, etc.
  notes: "Partial payment",        // Optional: admin notes
  
  // Stripe integration (if paid via Stripe)
  stripe_payment_intent_id: "pi_xyz123", // Stripe payment intent ID (null for manual)
  stripe_session_id: "cs_xyz123",       // Stripe checkout session ID (null for manual)
  
  // Audit trail
  recorded_by: "admin@handyworks.com", // Who recorded this payment
  created_at: Timestamp,                // When record was created
  
  // Status (for potential refunds/corrections)
  status: "completed"               // completed, refunded, pending
}
```

## Payment Methods

Valid values for `payment_method` field:

| Value          | Description                    | payment_reference Example    |
|----------------|--------------------------------|------------------------------|
| `stripe`       | Stripe online payment          | `pi_1234567890abcdef`       |
| `check`        | Check payment by mail          | `Check #1234`               |
| `credit_card`  | Manual credit card (phone/fax) | `Auth Code: 123456`         |
| `phone_card`   | Credit card via phone          | `Auth Code: 123456`         |
| `fax_card`     | Credit card via fax            | `Auth Code: 123456`         |
| `cash`         | Cash payment                   | `Receipt #123`              |
| `other`        | Other payment method           | `Bank transfer`             |

## Query Patterns

### Get all payments for an invoice
```javascript
db.collection('handyworks_payments')
  .where('invoice_id', '==', 'INV-2026-12345')
  .orderBy('payment_date', 'asc')
  .get()
```

### Get all payments for a customer
```javascript
db.collection('handyworks_payments')
  .where('acct_num', '==', 12345)
  .orderBy('payment_date', 'desc')
  .get()
```

### Calculate total paid for an invoice
```javascript
const paymentsSnapshot = await db.collection('handyworks_payments')
  .where('invoice_id', '==', 'INV-2026-12345')
  .get();

const totalPaid = paymentsSnapshot.docs.reduce((sum, doc) => {
  return sum + doc.data().amount;
}, 0);
```

## Invoice Status Calculation

Invoice `payment_status` is automatically calculated based on payments:

```javascript
function calculateInvoiceStatus(invoice, payments) {
  const totalPaid = payments.reduce((sum, p) => sum + p.amount, 0);
  const amountOwed = invoice.amount - totalPaid;
  
  if (amountOwed <= 0) {
    return 'paid';
  } else if (invoice.due_date && new Date() > invoice.due_date) {
    return 'overdue';
  } else {
    return 'pending';
  }
}
```

## Firestore Security Rules

```javascript
match /handyworks_payments/{paymentId} {
  // Admins can read/write all payments
  allow read, write: if request.auth != null && 
                        request.auth.token.admin == true;
  
  // Regular users cannot access payment records
  allow read, write: if false;
}
```

## Integration with Invoices

### Invoice Document Updates

Invoices in `handyworks_invoices` should NOT store payment amounts directly. Instead:
- Query `handyworks_payments` to calculate totals
- Update `payment_status` based on payment totals
- Store `paid_date` when status changes to 'paid'

### Automatic Payment Recording (Stripe Webhook)

When Stripe webhook fires (`payment_intent.succeeded`):

```javascript
// In stripeWebhook cloud function
const payment = {
  invoice_id: metadata.invoice_id,
  acct_num: metadata.acct_num,
  customer_name: metadata.customer_name,
  customer_email: metadata.customer_email,
  amount: paymentIntent.amount_received / 100, // Convert cents to dollars
  payment_date: firebase.firestore.Timestamp.now(),
  payment_method: 'stripe',
  payment_reference: paymentIntent.id,
  stripe_payment_intent_id: paymentIntent.id,
  stripe_session_id: session.id,
  recorded_by: 'system_webhook',
  created_at: firebase.firestore.Timestamp.now(),
  status: 'completed'
};

await db.collection('handyworks_payments').add(payment);

// Then update invoice status
const payments = await getPaymentsForInvoice(invoice_id);
const totalPaid = payments.reduce((sum, p) => sum + p.amount, 0);

if (totalPaid >= invoice.amount) {
  await db.collection('handyworks_invoices').doc(invoiceDocId).update({
    payment_status: 'paid',
    paid_date: firebase.firestore.Timestamp.now(),
    updated_at: firebase.firestore.Timestamp.now()
  });
}
```

### Manual Payment Recording (Admin Dashboard)

When admin records manual payment:

```javascript
// In admin dashboard
async function recordManualPayment(invoiceId, paymentData) {
  const payment = {
    invoice_id: invoiceData.invoice_id,
    acct_num: invoiceData.acct_num,
    customer_name: invoiceData.customer_name,
    customer_email: invoiceData.customer_email,
    amount: parseFloat(paymentData.amount),
    payment_date: firebase.firestore.Timestamp.now(),
    payment_method: paymentData.method,
    payment_reference: paymentData.reference || '',
    notes: paymentData.notes || '',
    stripe_payment_intent_id: null,
    stripe_session_id: null,
    recorded_by: auth.currentUser.email,
    created_at: firebase.firestore.Timestamp.now(),
    status: 'completed'
  };
  
  await db.collection('handyworks_payments').add(payment);
  
  // Recalculate and update invoice status
  await updateInvoiceStatus(invoiceId);
}
```

## Benefits of This Design

✅ **Immutable Records**: Each payment is a separate, unchangeable record  
✅ **Audit Trail**: Know who recorded what, when, and how  
✅ **Partial Payments**: Support multiple payments per invoice naturally  
✅ **Query Flexibility**: Easy to query by invoice, customer, date, method  
✅ **Scalability**: No array size limits (Firestore arrays limited to 1MB)  
✅ **Refunds**: Can add refund records with negative amounts if needed  
✅ **Unified History**: Stripe and manual payments in same collection  

## Migration Notes

**Existing Invoices**: Invoices created before this schema have payment tracking in the invoice document itself (`paid_amount`, `paid_date`). These should be migrated to payment records:

```javascript
// Migration script (run once)
async function migrateExistingPayments() {
  const invoices = await db.collection('handyworks_invoices')
    .where('payment_status', '==', 'paid')
    .get();
  
  for (const doc of invoices.docs) {
    const invoice = doc.data();
    
    // Only migrate if no payment records exist yet
    const existingPayments = await db.collection('handyworks_payments')
      .where('invoice_id', '==', invoice.invoice_id)
      .get();
    
    if (existingPayments.empty && invoice.paid_amount > 0) {
      await db.collection('handyworks_payments').add({
        invoice_id: invoice.invoice_id,
        acct_num: invoice.acct_num,
        customer_name: invoice.customer_name,
        customer_email: invoice.customer_email,
        amount: invoice.paid_amount,
        payment_date: invoice.paid_date || invoice.updated_at,
        payment_method: invoice.payment_method || 'unknown',
        payment_reference: invoice.stripe_payment_intent_id || '',
        notes: 'Migrated from invoice record',
        stripe_payment_intent_id: invoice.stripe_payment_intent_id,
        recorded_by: 'system_migration',
        created_at: firebase.firestore.Timestamp.now(),
        status: 'completed'
      });
    }
  }
}
```
