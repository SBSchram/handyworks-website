📝 Email Template Editor

Edit your email template. Use placeholders like [Greeting], [Year], [CardAmount] that will be replaced with actual data when sending.

Template type: (Reminder is for follow-up emails to customers who haven’t paid yet.)

← Back to Admin Dashboard

Available Placeholders:

  • [Greeting] - Formatted greeting (e.g., "Hi Dr. Smith,")
  • [Lastname] - Customer's last name
  • [Firstname] - Customer's first name
  • [Fullname] - Customer's full name
  • [Year] - Invoice year (e.g., "2026")
  • [CardAmount] - Card payment amount (e.g., "555")
  • [CheckAmount] - Check payment amount (e.g., "540")
  • [CheckDiscount] - Discount amount (e.g., "15")
  • [PaymentLink] - Stripe payment link URL
  • [PaymentLinkText] - Payment link button text
  • [Address] - Mailing address for checks
  • [SupportPhone] - Support phone number
  • [FaxNumber] - Fax number
  • [Signature] - Signature line (e.g., "Dr. Steve")
  • [BusinessName] - Business name (e.g., "HandyWorks Software")
  • [StreetAddress] - Street address (e.g., "140 E 28th Street Suite 1F")
  • [CityStateZip] - City, State, ZIP (e.g., "New York City, NY 10016")
  • [PhoneNumber] - Phone number (e.g., "212-889-8878")
  • [SupportEmail] - Support email address (optional)
